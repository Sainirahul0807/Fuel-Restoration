Build a complete, production-ready, fully functional website called **"Fuel Restoration"** for a startup that collects used cooking oil from households (home-to-home pickup) to reduce oil waste and resells it to biodiesel factories.

## Tech Stack & Setup
- Build it as a **React** application (Vite + React, functional components + hooks).
- Fully compatible with **GitHub** (push directly to a connected GitHub repository) and deployable on **Vercel** with zero configuration changes.
- Clean, logically organized folder structure: `/src/components`, `/src/pages`, `/src/assets`, `/src/data`, `/src/styles`. Include a proper `README.md`, `.gitignore`, and `package.json`.
- No console errors, no broken imports, no missing dependencies — the app must run immediately with `npm install && npm run dev` and build cleanly with `npm run build`.
- Fully responsive (mobile, tablet, desktop).

## Visual Theme
- **Sharp-edged design language**: no rounded corners, angular cards/buttons/sections, bold geometric dividers.
- Dark/deep background (e.g., charcoal, deep green, or near-black) with **light-coloured text** (white / off-white / soft cream) for strong contrast.
- Accent colour inspired by biodiesel/eco themes (amber-gold for oil, green for sustainability).
- Modern sans-serif typography, generous whitespace, subtle hover/scroll animations (no rounded softness — keep it crisp and industrial).
